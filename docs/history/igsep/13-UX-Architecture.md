# Purpose

Dokumen ini mendefinisikan User Experience Architecture seluruh platform.

UX bukan hanya tampilan.

UX adalah bagaimana pengguna menyelesaikan pekerjaan dengan lebih cepat, lebih mudah, dan lebih sedikit kesalahan.

Platform harus terasa seperti SaaS modern, bukan ERP tradisional.
